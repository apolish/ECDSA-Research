Abstract

We study a finite combinatorial object: the state space of an idealised ECDSA signer, together with a family of subsets of it defined by exact arithmetic coincidences between the hidden pair $(s_{zk},s_{rxk})=(zk^{-1},rxk^{-1})$ and quantities computable from public data. Three such subsets — the classes $\mathrm{A}$, $\mathrm{B}$ and $\mathrm{E}$ of an earlier classification — are analysed in closed form.

The organising result is Theorem 20 (zero yield). Let $R$ be any rule that maps the public data of a signature to a set $C$ of candidate values for the hidden component. Then $$\Pr\bigl[s_{zk}\in C\bigr]\;=\;\frac{\mathbb{E}\bigl|C\bigr|}{\,n-2\,},$$ exactly. The success probability per tested candidate is therefore the constant $1/(n-2)$ for every rule, identical to drawing candidates uniformly at random from $\mathbb{Z}_n^{*}\setminus\{s\}$. Classification cannot change the yield; it can only change how many candidates are emitted. The classes are subsets, their frequencies are cardinalities, and that is the whole theory.

Instantiating the theorem gives the exact frequencies, which we prove and verify by exhaustive enumeration of $1.66\times10^{9}$ states: class $\mathrm{A}$ emits $\mathbb{E}|C|=\tfrac14$ candidates per signature and occurs with probability $\Pr[\mathcal{Q}]/(n-2)$, an identity; class $\mathrm{E}$ emits $\tfrac56$ and is shown to be exactly the affine locus $s_{zk}=3\,s_{rxk}+2$, whence $\Pr[\mathrm{E}]=2\lfloor(n-3)/3\rfloor/(n-1)^{2}\sim\tfrac{2}{3n}$ — correcting a published value of $1/(n-1)$ that the source data already rejected at $32\sigma$; class $\mathrm{B}$ emits $\Theta(n^{-1}\log n)$ and its multiplier satisfies an integer quadratic, so no modular square root arises. Three further structural facts fall out: the qualification rate is exactly $1/4$ for every curve, being the area of a lattice region; the "Goldbach" offset in class $\mathrm{E}$ is one of $\Theta(n)$ interchangeable choices; and the recovery formulas of the classification are a single Möbius bijection in disguise.

Evaluated on secp256k1 the frequencies are $2^{-258.00}$, $2^{-256.58}$ and $\approx2^{-506.9}$. We report these because the question was asked, not because they matter: by Theorem 20 the entire framework improves on uniform random key guessing by a factor of exactly $1+1/(n-2)\approx1+10^{-77}$, and that residual advantage comes from the trivial observation $s_{zk}\neq s$ rather than from any of the algebra. Random guessing is itself $\approx2^{128}$ times worse than Pollard rho. The correct reading of this work is that a natural and appealing line of enquiry is closed, with proofs, and need not be reopened.

Section 1What this paper is

This is a note in finite combinatorics. The object of study is a product set of size $(n-1)^{3}$ and a family of its subsets; ECDSA is where the object comes from, not a domain in which anything here is applied.

1.1The question, stated abstractly

A signature determines three quantities: two hidden, $\zeta=zk^{-1}$ and $\xi=rxk^{-1}$, and a family of public ones. An earlier classification of this project singled out several subsets of the state space on which $\zeta$ satisfies an exact arithmetic relation with a publicly computable target — equality with a remainder ($\mathrm{A}$), a shared integer quotient ($\mathrm{B}$), a fixed additive difference ($\mathrm{E}$). The questions are then purely enumerative:

  1. What is each subset, described as simply as possible?
  2. How large is it, exactly, as a function of $n$?
  3. Is there any structure in the family — any reason one subset should be more interesting than another?

The answers, in order, are: an affine locus or a graph of a function (§5, §7); a closed-form cardinality (Theorems 10, 17, Proposition 14); and no (Theorem 20). The third answer subsumes the first two and is the reason the paper exists.

1.2What this paper is not

It is not a vulnerability disclosure, an attack, a partial attack, a weakening of parameters, or a research lead. It contains formulas that map a correct guess of $\zeta$ to the private key, and those formulas work; but by Proposition 3 they are a single Möbius bijection, i.e. a change of coordinates on a search space of size $n-1$, and by Theorem 20 no rule computable from public data can make the guess better than uniform. Reading the recovery formulas as an attack is a category error, and the earlier "vulnerability" framing of this project's own publications was wrong.

Nor is the practical irrelevance a matter of parameters being merely large. It is structural. The obstruction proved in §10 is information-theoretic: conditioning on every public quantity leaves the conditional distribution of $\zeta$ uniform on $n-2$ values, so there is no leakage for any algorithm, present or future, to amplify. Bigger curves are not the defence; the absence of leakage is.

1.3On the word "anomaly"

Terminology

The labels $\mathrm{A}$, $\mathrm{B}$, $\mathrm{E}$ are kept for continuity with the project's notation, but "anomaly" is the wrong noun and so is "artifact". An anomaly is a departure from what a model predicts; an artifact is a distortion introduced by the instrument. These classes are neither. They occur at precisely the rate that the null model of perfectly uniform nonces predicts — that is the content of Theorems 10, 17 and 20 — and nothing in the measurement produced them.

The accurate term is coincidence class: a subset of the state space picked out by an exact numerical accident. Coincidence classes are not surprising, not rare in absolute terms ($\sim10^{231}$ instances exist on secp256k1), and not informative. They are simply what a uniform distribution looks like when a large enough region of it is enumerated and a sufficiently specific pattern is looked for.

1.4What counts as a contribution here, and what does not

Honesty about novelty is part of the reframing, so it is stated plainly. The following are genuine, checkable contributions, all elementary:

  • Theorem 20 — a complete no-go statement for the entire family of classifications, replacing an open-ended search with a closed question. This is the only result here with any generality.
  • Theorem 16 — the collapse of an ornate three-clause definition (class $\mathrm{E}$) into the single line $\zeta=3\xi+2$. Definitions that hide their own triviality are worth unmasking.
  • Theorems 7, 10, 17 — exact closed forms where the prior work had heuristics, two of which were numerically wrong.
  • Theorem 12 and Lemma 13 — the observation that class $\mathrm{B}$ lives over $\mathbb{Z}$, not over $\mathbb{Z}_n$.

The following are not contributions and should not be presented as such: the recovery formulas (Proposition 3 shows they are one bijection); the taxonomy $\mathrm{A}$–$\mathrm{E}$ itself (an arbitrary partition of the analyst's bookkeeping, not of the object); and the observation that rare coincidences occur at rate $\Theta(1/n)$, which is folklore. The overall weight of the work is that of a careful technical note recording a closed line of enquiry — not of a research advance, and it should be circulated as the former.

Section 2Preliminaries and notation

2.1The signing equation

Let $E/\mathbb{F}_p$ be an elliptic curve with a base point $G$ of prime order $n$, and let $Q=xG$ be the public key of a private key $x\in\{1,\dots,n-1\}$. For a message hash $z\in\{1,\dots,n-1\}$ and a nonce $k\in\{1,\dots,n-1\}$ the ECDSA signature is

$$r=\bigl[kG\bigr]_{x}\bmod n,\qquad s=(z+rx)\,k^{-1}\bmod n. \tag{2.1}$$

Throughout, $\mathbb{Z}_n^{*}=\{1,\dots,n-1\}$ (a field minus zero, since $n$ is prime), and every element of $\mathbb{Z}_n$ is identified with its representative in $\{0,1,\dots,n-1\}$. This identification is essential: the anomaly conditions mix modular arithmetic with ordinary integer comparison, divisibility and order. Whenever a relation is meant over $\mathbb{Z}$ rather than over $\mathbb{Z}_n$ this is stated explicitly.

2.2The hidden additive decomposition

Definition 1  (hidden components)

$$\zeta:=s_{zk}=z\,k^{-1}\bmod n,\qquad \xi:=s_{rxk}=r\,x\,k^{-1}\bmod n. \tag{2.2}$$ By (2.1), $s\equiv\zeta+\xi \pmod n$. Both are unobservable from $(r,s,z)$.

Because the representatives lie in $\{1,\dots,n-1\}$, the integer sum $\sigma:=\zeta+\xi\in\{2,\dots,2n-2\}$ satisfies exactly one of

$$\sigma=s \quad(\text{no wrap-around}),\qquad\text{or}\qquad \sigma=s+n \quad(\text{wrap-around}). \tag{2.3}$$

The distinction is invisible publicly and matters for classes $\mathrm{B}$ and $\mathrm{E}$.

Definition 2  (public auxiliary quantities)

$$s_{zr}:=z\,r\bmod n,\qquad d:=s_{zr}-s \ \ (\text{defined when } s_{zr}>s),\qquad a:=s\bmod d, \tag{2.4}$$ the last being an integer remainder. All three are computable from $(z,r,s)$, i.e. from the signature together with the signed message.

2.3The one identity behind every recovery formula

Proposition 3  (master identity, and why it is a relabelling)

(i) If $\hat{s}$ equals the true hidden component $\zeta$, then $$x \;=\; z\,(s-\hat{s})\,\bigl(r\,\hat{s}\bigr)^{-1}\bmod n. \tag{2.5}$$ (ii) The map $\varphi:\mathbb{Z}_n^{*}\setminus\{s\}\to\mathbb{Z}_n^{*}$, $\varphi(\hat{s})=z(s-\hat{s})(r\hat{s})^{-1}\bmod n$, is injective. Consequently, knowing $\zeta$ is equivalent to knowing $x$: neither is easier to guess than the other, and (2.5) transports no information from the public data to the secret.

(i) From Definition 1, $k=z\zeta^{-1}$ and $\xi=(s-\zeta)\bmod n$. Substituting into $\xi=rxk^{-1}$ gives $x=\xi\,(rk^{-1})^{-1}=\xi\,k\,r^{-1} =(s-\zeta)\cdot z\zeta^{-1}\cdot r^{-1}=z(s-\zeta)(r\zeta)^{-1}$. (ii) Expand: $\varphi(\hat{s})=z s r^{-1}\hat{s}^{-1}-z r^{-1}$. The inversion $\hat{s}\mapsto\hat{s}^{-1}$ is a bijection of $\mathbb{Z}_n^{*}$, and $t\mapsto (zsr^{-1})t-zr^{-1}$ is an affine bijection because $zsr^{-1}\neq0$ in the field $\mathbb{Z}_n$. A composition of bijections is injective.

Proposition 3(ii) is the structural fact that governs the entire subject. Searching for $x$ through $\hat{s}$ is a change of coordinates on the same search space of size $n-1$. Every class below is therefore nothing more than a rule for proposing candidate values of $\zeta$, and the only quantity that matters is: how often is the proposal correct, and how many proposals does it cost?

Section 3The probability model

3.1Assumptions

Assumption U  (ideal signer)

$z$, $x$ and $k$ are drawn independently and uniformly from $\mathbb{Z}_n^{*}$.

Assumption R  (abscissa heuristic)

$r=[kG]_x\bmod n$ is modelled as uniform on $\mathbb{Z}_n^{*}$ and independent of $(z,x,k)$.

Assumption U is the definition of a correctly implemented signer; if it fails, ECDSA is broken by mechanisms that have nothing to do with this paper (§12). Assumption R is a genuine heuristic: $r$ is a deterministic function of $k$, so exact independence is false. It is adopted because the $x$-coordinate map on a curve of prime order has no known algebraic correlation with the multiplicative structure used below, and — more importantly — because every prediction derived from it is verified in §8 against data generated on actual elliptic curves, where no such assumption was made. The agreement is within Poisson noise across five orders of magnitude in $n$ and eight in sample size. Assumption R is therefore not load-bearing for the numerical conclusions; it is a device for obtaining closed forms.

3.2The state of a transaction

Lemma 4  (uniformity and independence of the state)

Put $u:=kr\bmod n$. Under Assumptions U and R:

(i) $(\zeta,\xi,u)$ is uniformly distributed on $(\mathbb{Z}_n^{*})^{3}$;
(ii) the map $(\zeta,\xi,u)\mapsto(\zeta,s,s_{zr})$ with $s=\zeta+\xi$, $s_{zr}=\zeta u$ (both mod $n$) is a bijection onto $$\mathcal{S}=\bigl\{(\zeta,s,s_{zr}) : \zeta\in\mathbb{Z}_n^{*},\; s\in\mathbb{Z}_n\setminus\{\zeta\},\; s_{zr}\in\mathbb{Z}_n^{*}\bigr\},$$ so $(\zeta,s,s_{zr})$ is uniform on $\mathcal{S}$, and $|\mathcal{S}|=(n-1)^3$;
(iii) in particular $s_{zr}$ is uniform on $\mathbb{Z}_n^{*}$ and independent of $(\zeta,s)$, and for each fixed $s\neq0$ the conditional law of $\zeta$ given $(s,s_{zr})$ is uniform on $\mathbb{Z}_n^{*}\setminus\{s\}$, a set of $n-2$ elements.

(i) Fix $k$ and $r$. Then $\zeta=zk^{-1}$ is a bijective image of the uniform $z$, hence uniform on $\mathbb{Z}_n^{*}$; $\xi=rxk^{-1}$ is a bijective image of the uniform $x$, hence uniform; they are independent because $z\perp x$. Neither depends on the value of $u=kr$, which is a function of $(k,r)$ alone; by Assumption R, $u$ is uniform on $\mathbb{Z}_n^{*}$ (a product of a uniform unit with anything is uniform) and independent of $(z,x)$, hence of $(\zeta,\xi)$. (ii) The map is invertible: $\xi=s-\zeta$, $u=s_{zr}\zeta^{-1}$. Its image is exactly $\mathcal{S}$: $\xi\neq0\iff s\neq\zeta$, and $u\neq0\iff s_{zr}\neq0$. A bijection carries the uniform law to the uniform law, and $|\mathcal{S}|=(n-1)\cdot(n-1)\cdot(n-1)$ because for each $\zeta$ there are $n-1$ admissible $s$ in $\mathbb{Z}_n\setminus\{\zeta\}$. (iii) Immediate from the product structure of $\mathcal{S}$: $s_{zr}$ ranges over $\mathbb{Z}_n^{*}$ freely, and for fixed $(s,s_{zr})$ with $s\neq0$ the admissible $\zeta$ are $\mathbb{Z}_n^{*}\setminus\{s\}$.

Lemma 4(iii) is the workhorse. It says that after the analyst has computed everything that can be computed — $s$, $s_{zr}$, $d$, $a$, and any function of them — the hidden component $\zeta$ is still uniform over $n-2$ possibilities. That is the precise sense in which the anomaly framework cannot extract information: the conditioning on public data leaves the secret's conditional entropy at $\log_2(n-2)$ bits, i.e. essentially untouched.

Section 5Anomaly class A — linear divisibility with unit multiplier

5.1Definition and recovery

Definition 8  (class A)

A qualified transaction is in class $\mathrm{A}$ if the divisibility ratio $m_1=\zeta/a$, computed in $\mathbb{Q}$, equals $1$; equivalently $$\boxed{\;\zeta=a\;}\qquad\text{as integers.} \tag{5.1}$$ (The strict taxonomy of the source framework additionally requires $m_2=(s+s_{zr})/\xi\notin\mathbb{Z}$, which separates $\mathrm{A}$ from $\mathrm{B}$; by Theorem 12 that refinement removes an $O(n^{-2}\log n)$ fraction and is invisible at every scale considered here.)

Theorem 9  (recovery for class A)

On a class-$\mathrm{A}$ transaction the private key is recovered by a single evaluation: $$k=a\,z^{-1}\bmod n,\qquad x=(s-a)\,(r\,k)^{-1}\bmod n \;=\;z\,(s-a)\,(r\,a)^{-1}\bmod n. \tag{5.2}$$ One candidate is produced; it is correct with certainty on class-$\mathrm{A}$ inputs and is verified by one scalar multiplication $xG\stackrel{?}{=}Q$.

Substitute $\hat{s}=a=\zeta$ into Proposition 3(i). All inverses exist because $n$ is prime and $z,r,a\not\equiv0$.

5.3An instructive wrong turn

Correction 1 — the divisor-counting route

It is tempting to compute $\Pr[\mathrm{A}]$ by counting, for each $(s,\zeta)$, the divisors $d\mid(s-\zeta)$ with $d>\zeta$, and then approximating the resulting sum by an integral. Doing so yields $\Pr[\mathrm{A}]\approx0.3466/n$, which is $39\%$ too large and is rejected by the tiny-curve data at $16.8\sigma$. The error is instructive: the continuum approximation silently discards the fractional parts $\{(n-\zeta)/d\}$, whose systematic mean of $\tfrac12$ accumulates to a term of order $d$ under the $\zeta$-summation. Carrying the floors exactly gives $\sum_{\zeta=0}^{d-1}\lfloor (M-\zeta)/d\rfloor=M-d+1$, and the corrected total is $M^{2}/4$, in agreement with Theorem 10. Lattice counts in this subject are dominated by their floor terms; integral approximations to them should be distrusted by default.

Section 6Anomaly class B — dual integral divisibility

6.1Definition

Definition 11  (class B)

A qualified transaction is in class $\mathrm{B}$ if both ratios $$m_1=\frac{\zeta}{a},\qquad m_2=\frac{s+s_{zr}}{\xi}$$ are integers and $m_1=m_2=:m$. Both quotients are taken in $\mathbb{Q}$, i.e. they assert exact divisibility over $\mathbb{Z}$, not congruences.

6.2The multiplier satisfies an integer quadratic

Theorem 12  (class-B recovery, over $\mathbb{Z}$)

On a class-$\mathrm{B}$ transaction, with $\sigma\in\{s,\;s+n\}$ the true integer sum (2.3), the multiplier $m$ satisfies the integer quadratic $$a\,m^{2}\;-\;\sigma\,m\;+\;(s+s_{zr})\;=\;0 \qquad\text{in }\mathbb{Z}. \tag{6.1}$$ Consequently the discriminant $\Delta=\sigma^{2}-4a(s+s_{zr})$ is a perfect square in $\mathbb{Z}$, and $$m=\frac{\sigma\pm\sqrt{\Delta}}{2a}\in\mathbb{Z},\qquad \zeta=am,\qquad x=z(s-\zeta)(r\zeta)^{-1}\bmod n. \tag{6.2}$$ At most four candidates arise (two roots $\times$ two branches of $\sigma$), each checked by one scalar multiplication.

By definition $\zeta=am$ and $s+s_{zr}=m\xi$, both over $\mathbb{Z}$. By (2.3), $\xi=\sigma-\zeta=\sigma-am$. Substituting, $s+s_{zr}=m(\sigma-am)=\sigma m-am^{2}$, which is (6.1). Since $a,\sigma,s,s_{zr},m$ are integers, (6.1) forces $\Delta=\sigma^2-4a(s+s_{zr})$ to be a perfect square by the rational root/quadratic formula over $\mathbb{Z}$.
Correction 2 — no modular square root is required

The previously published statement of this theorem reduced (6.1) modulo $n$, computed $\sqrt{\Delta}\bmod n$ via the Euler criterion, and inverted $2a$ modulo $n$. That procedure is not wrong, but it is strictly weaker and needlessly expensive: it discards the fact that the relation holds over $\mathbb{Z}$, where the constraint "$\Delta$ is a perfect square" is far more restrictive than "$\Delta$ is a quadratic residue mod $n$" (density $\Theta(\Delta^{-1/2})$ versus $1/2$). It also fixed $\sigma=s$, silently assuming no wrap-around. In exhaustive enumeration for $n\le1009$ — $3\,823$ class-$\mathrm{B}$ instances in total — the integer discriminant was a perfect square in every single case, confirming (6.1).

Lemma 13  (wrap-around is nearly impossible in class B)

If a class-$\mathrm{B}$ transaction has $\sigma=s+n$, then $m\le2$, and moreover $$m=1\;\Longrightarrow\; s_{zr}+a=n,\qquad\qquad m=2\;\Longrightarrow\; d \text{ is even and } 4a+d=2n .$$

Qualification gives $d\le s$, so $s+s_{zr}=2s+d\le3s$. Also $\xi=\sigma-\zeta=s+n-\zeta\ge s+1$ because $\zeta\le n-1$. From $m\xi=s+s_{zr}$, $$m=\frac{s+s_{zr}}{\xi}\le\frac{3s}{s+1}<3 .$$ For $m=1$: $\xi=2s+d$ and $\xi=s+n-a$ give $n=s+d+a=s_{zr}+a$. For $m=2$: $2\xi=2s+d$ forces $d$ even with $\xi=s+d/2$, while $\xi=s+n-2a$; equating gives $2n=4a+d$.

Each of those is one exact equation between quantities of size $\Theta(n)$, hence a codimension-one condition on top of an already $O(n^{-2})$-rare event. No wrap-around instance occurred in the exhaustive enumeration. An implementation should nonetheless test both branches of $\sigma$; the cost is one extra scalar multiplication.

6.3Frequency

Class $\mathrm{B}$ does not admit the clean conditioning argument used for $\mathrm{A}$, because it constrains $\zeta$ and $\xi$ simultaneously through a divisor structure. We give a heuristic derivation and then an empirical calibration; the two agree to within $25\%$.

Proposition 14  (order of magnitude of $\Pr[\mathrm{B}]$)

Under the divisor-equidistribution heuristic, $$\Pr[\mathrm{B}]\;=\;\Theta\!\left(\frac{\log n}{n^{2}}\right), \qquad\text{with}\qquad \Pr[\mathrm{B}]\approx\frac{c_B\log n}{n^{2}},\;\; c_B\approx0.19 . \tag{6.3}$$

Fix $(s,s_{zr})$ qualified. Class $\mathrm{B}$ selects those $\zeta$ for which some $m\mid$-compatible pair exists: $\zeta=am$ and $\xi=(s+s_{zr})/m$. Each divisor $m$ of $s+s_{zr}$ determines a unique candidate pair, so at most $\tau(s+s_{zr})$ candidates occur; the pair survives only if additionally $\zeta+\xi\in\{s,s+n\}$, a coincidence of "probability" $\Theta(1/n)$ under equidistribution. Since the mean of $\tau$ on $[1,2n]$ is $\log n+O(1)$, the conditional rate is $\Theta(n^{-1}\log n)\cdot n^{-1}$, and multiplying by $\Pr[\mathcal{Q}]=\tfrac14$ gives $\approx\tfrac14 n^{-2}\log n$. Exhaustive enumeration over the full state space for $n=101,\dots,1009$ gives $\Pr[\mathrm{B}]\,n^{2}/\log n\in[0.189,\,0.196]$, remarkably flat over an order of magnitude in $n$; hence $c_B\approx0.19$, within $25\%$ of the heuristic constant $\tfrac14$.
Honesty note on (6.3)

The measured ratio drifts downward by about $3\%$ across the accessible range, so the true law may carry a sub-logarithmic correction that this data cannot resolve; the accessible range spans only one decade of $n$ while the extrapolation target spans $74$. This is stated plainly because it is the weakest link in the paper. It is also irrelevant: an error of two orders of magnitude in $c_B$ moves $\Pr[\mathrm{B}]$ on secp256k1 from $10^{-153}$ to somewhere between $10^{-155}$ and $10^{-151}$, and every conclusion in §9–§11 is unchanged. By contrast, the class-$\mathrm{A}$ and class-$\mathrm{E}$ formulas are exact for every $n$ and involve no extrapolation at all.

Section 7Anomaly class E — the "Goldbach-type" decomposition

Class $\mathrm{E}$ is the most interesting of the three, because its published description is ornate and its actual content is a single line. We prove that the class is exactly an affine lattice line in the hidden-pair plane, obtain its cardinality in closed form, and show that the "Goldbach" offset that gives the class its name carries no information at all.

7.1Definition

Definition 15  (classes E1 and E2)

Let $\sigma=\zeta+\xi$ be the integer sum (2.3). A transaction is in class $\mathrm{E}$ if $\sigma$ is even and $$\bigl|\zeta-\xi\bigr| \;=\; \frac{\sigma}{2}+1 . \tag{7.1}$$ Instances with $\sigma=s$ are labelled $\mathrm{E1}$ (no wrap-around) and those with $\sigma=s+n$ are labelled $\mathrm{E2}$. The published formulation writes $\lfloor\sigma/2\rfloor+1$; since $\sigma$ is required to be even, the floor is vacuous.

7.2Structure theorem

Theorem 16  (class E is an affine line)

For integers $\zeta,\xi\ge1$, condition (7.1) together with "$\sigma$ even" holds if and only if $$\boxed{\;\zeta=3\xi+2\quad\text{or}\quad \xi=3\zeta+2\;}\qquad\text{in }\mathbb{Z}. \tag{7.2}$$ Moreover every class-$\mathrm{E}$ instance satisfies $\sigma\equiv2\pmod 4$, and the two branches are disjoint.

($\Rightarrow$) Equality (7.1) rules out $\zeta=\xi$, since its right-hand side is positive. Take $\zeta>\xi$ without loss of generality. Then $\zeta-\xi=\tfrac{\zeta+\xi}{2}+1$, i.e. $2\zeta-2\xi=\zeta+\xi+2$, i.e. $\zeta=3\xi+2$. ($\Leftarrow$) If $\zeta=3\xi+2$ then $\sigma=4\xi+2$ is even and $\zeta-\xi=2\xi+2=\tfrac{\sigma}{2}+1$, so (7.1) holds. Since $\sigma=4\xi+2$ we get $\sigma\equiv2\pmod4$. Finally, if both branches held then $\zeta=3(3\zeta+2)+2=9\zeta+8$, forcing $\zeta=-1$, impossible for a positive integer.
Interpretation

Theorem 16 dissolves the "Goldbach" framing. The published description — "a symmetric pair around $\sigma/2$ with fixed difference" — is doubly vacuous: every pair summing to $\sigma$ is symmetric about $\sigma/2$ by construction, and the only real content of (7.1) is that the hidden pair lies on one particular line of slope $3$. There is no additive number theory here, no partition structure, and no connection to the Goldbach problem beyond the superficial fact that a number is being written as a sum of two others.

7.3Exact frequency

Theorem 17  (exact probability of class E)

For every prime $n\ge5$, the number of class-$\mathrm{E}$ hidden pairs in $\{1,\dots,n-1\}^{2}$ is $$\#\mathrm{E}\;=\;2\left\lfloor\frac{n-3}{3}\right\rfloor , \tag{7.3}$$ and therefore $$\Pr[\mathrm{E}]\;=\;\frac{2\bigl\lfloor (n-3)/3\bigr\rfloor}{(n-1)^{2}} \;=\;\frac{2}{3n}+O\!\left(\frac{1}{n^{2}}\right). \tag{7.4}$$

By Theorem 16 the class is the disjoint union of two branches. On the branch $\zeta=3\xi+2$ the constraints are $\xi\ge1$ and $3\xi+2\le n-1$, i.e. $1\le\xi\le(n-3)/3$, giving $\lfloor(n-3)/3\rfloor$ solutions; the branch $\xi=3\zeta+2$ gives the same count by symmetry. Class $\mathrm{E}$ depends only on $(\zeta,\xi)$, which by Lemma 4(i) is uniform on $(\mathbb{Z}_n^{*})^{2}$, a set of $(n-1)^{2}$ elements; no class-$\mathrm{E}$ pair is removed by the constraint $s\neq0$, because $\sigma=4\xi+2=n$ would force $n$ even.
Theorem 18  (recovery for class E)

Given the effective sum $\sigma\in\{s,\,s+n\}$ with $\sigma\equiv2\pmod4$, put $$\alpha=\frac{3\sigma+2}{4},\qquad \beta=\sigma-\alpha=\frac{\sigma-2}{4} . \tag{7.5}$$ Then $\{\zeta,\xi\}=\{\alpha,\beta\}$, and the private key is one of $x_{c}=z\,(s-c)\,(r\,c)^{-1}\bmod n$ for $c\in\{\alpha,\beta\}$, disambiguated by one scalar multiplication. At most four candidates arise over the two branches of $\sigma$.

Solve the linear system $\zeta+\xi=\sigma$, $\zeta-\xi=\sigma/2+1$: adding gives $2\zeta=\tfrac{3\sigma}{2}+1$, i.e. $\zeta=\tfrac{3\sigma+2}{4}$, which is an integer precisely because $\sigma\equiv2\pmod4$ (Theorem 16). Apply Proposition 3(i) to each candidate.

7.4Correction to the published frequency

Correction 3 — $\Pr[\mathrm{E}]$ is $2/(3n)$, not $1/(n-1)$

The framework document for this project states $\Pr[\mathrm{E}]=1/(n-1)$, reasoning that the condition "fixes $s_{zk}$ to at most $2$ values" and that "exactly one of $s,\;s+n$ is even". The second clause is correct but the first over-counts: the parity analysis in Theorem 16 shows that an even $\sigma$ admits a solution only when $\sigma\equiv2\pmod4$, which removes half of the even sums, and the surviving locus is the line $\zeta=3\xi+2$ of length $\approx n/3$ per branch rather than $\approx n/2$. The correct rate is $2/(3n)$, i.e. $\tfrac23$ of the published value.

7.5The "+1" offset is arbitrary — proved, not merely observed

Theorem 19  (offset invariance)

For any fixed integer $c$, define the class $\mathrm{E}_{c}$ by "$\sigma$ even and $|\zeta-\xi|=\sigma/2+c$". Then $$\mathrm{E}_{c}=\{\zeta=3\xi+2c\}\;\sqcup\;\{\xi=3\zeta+2c\},$$ and for $|c|=o(n)$, $$\Pr[\mathrm{E}_{c}]=\frac{2}{3n}\Bigl(1+O\bigl(\tfrac{|c|}{n}\bigr)\Bigr),$$ independently of $c$. In particular the Goldbach value $c=1$ is in no way privileged: it is one member of a family of $\Theta(n)$ equally frequent classes.

Repeat the computation of Theorem 16 with the right-hand side $\sigma/2+c$: for $\zeta>\xi$, $2\zeta-2\xi=\zeta+\xi+2c$ yields $\zeta=3\xi+2c$; conversely $\sigma=4\xi+2c$ is even and $\zeta-\xi=2\xi+2c=\sigma/2+c$. Counting lattice points on the branch, $\#\{\xi: 1\le\xi\le n-1,\;1\le3\xi+2c\le n-1\}=\tfrac{n}{3}+O(|c|)$, and the second branch is symmetric.

The control experiment in the project repository (analysis/e_control.py) reports a flat frequency of $\approx0.67/n$ for offsets $c\in\{\pm1,3,5,7,9,101\}$. Theorem 19 explains that observation exactly: the constant $0.67\approx2/3$ is $\Pr[\mathrm{E}_{c}]\cdot n$, and its independence of $c$ is a two-line consequence of the affine structure. An empirical control that was run to test a hypothesis turns out to be a corollary of the hypothesis's own algebra.

The classes are not empty on secp256k1 — far from it. The transaction space $\mathcal{T}=\{1,\dots,n-1\}^{4}$ (free parameters $z,x,k,r$, with $s$ determined) has $|\mathcal{T}|\approx1.80\times10^{308}$ elements, of which

Section 10The zero-yield theorem

Sections 5–7 computed three cardinalities. This section shows that the computations were unnecessary in principle: every class in this family, and every class that could ever be added to it, has the same quality. Only its size varies.

10.1Classes as candidate-set rules

Definition  (public-data rule)

A rule is any map $R$ from the public data of a signature — the curve, $z$, $r$, $s$ and anything computable from them, such as $s_{zr}$, $d$, $a$ — to a finite set $C=R(z,r,s)\subseteq\mathbb{Z}_n^{*}$ of candidate values for the hidden component $\zeta$. Randomised rules are permitted, provided their randomness is independent of the signer's. The rule succeeds if $\zeta\in C$.

Every class of the classification is a rule in this sense. Class $\mathrm{A}$ emits $C=\{a\}$ on qualified transactions and $C=\varnothing$ otherwise. Class $\mathrm{E}$ emits the roots $\{\alpha,\beta\}$ of (7.5) for each branch $\sigma\in\{s,s+n\}$ with $\sigma\equiv2\pmod4$, discarding those outside $[1,n-1]$. Class $\mathrm{B}$ emits $\{am\}$ for each integer root $m$ of the quadratic (6.1) with square discriminant. Uniform random guessing is the rule $C=\{\text{t i.i.d. uniform draws}\}$.

10.2The theorem

Theorem 20  (zero yield)

For every rule $R$, $$\Pr\bigl[\zeta\in C\bigr]\;=\; \frac{\mathbb{E}\bigl|\,C\cap(\mathbb{Z}_n^{*}\setminus\{s\})\,\bigr|}{n-2} \;\le\;\frac{\mathbb{E}|C|}{n-2}. \tag{10.1}$$ In particular the success probability per candidate emitted is the constant $1/(n-2)$, independent of $R$.

By Lemma 4(ii) the triple $(\zeta,s,s_{zr})$ is uniform on the product set $\mathcal{S}$, so conditionally on the public data — which is a function of $(s,s_{zr})$ and of $r$, itself independent of $\zeta$ by Lemma 4(iii) — the hidden component $\zeta$ is uniform on $\mathbb{Z}_n^{*}\setminus\{s\}$, a set of exactly $n-2$ elements. The set $C$ is measurable with respect to that same public data (and independent auxiliary randomness), hence conditionally fixed. For a uniform variable on a set of size $n-2$ and a fixed subset $C$, $\Pr[\zeta\in C\mid\text{public}]=|C\cap(\mathbb{Z}_n^{*}\setminus\{s\})|/(n-2)$. Take expectations over the public data.
Corollary 21  (universal no-go)

No public-data classification of ECDSA signatures — existing, proposed, or not yet conceived — can achieve a per-candidate success rate different from $1/(n-2)$. In particular:

  • A rule cannot be better than uniform guessing on $\mathbb{Z}_n^{*}\setminus\{s\}$; equality in (10.1) is attained by that rule and by every rule emitting distinct candidates.
  • A rule can only be worse by emitting duplicates or by emitting the excluded value $s$; both are implementation defects, not properties of the class.
  • Against a guesser drawing uniformly from all of $\mathbb{Z}_n^{*}$, whose yield is $1/(n-1)$, the best possible rule wins by a factor of $$\frac{n-1}{n-2}\;=\;1+\frac{1}{n-2}\;=\;1+8.64\times10^{-78}\ \text{ on secp256k1.}$$ That advantage is purchased entirely by the observation $\zeta\neq s$, which requires no algebra at all.

10.4Correction to an earlier draft of this paper

Correction 4 — "worse than guessing by $3.3\times$" was an artefact of the cost accounting

An earlier draft compared an anomaly hunter processing $T$ signatures against a guesser making $3T$ guesses, and concluded that the hunter loses by a factor of $3.3$. The comparison is not wrong arithmetically, but the choice of $3T$ was arbitrary: it assumed the hunter tests three candidates per signature, whereas the classes actually emit $\mathbb{E}|C|\approx\tfrac14+\tfrac56+O(n^{-1}\log n)\approx1.083$ candidates per signature. Charging both adversaries the same number of scalar multiplications gives the correct comparison, and the answer is not a loss by $3.3\times$ but an exact tie, up to the factor $1+1/(n-2)$ of Corollary 21.

The corrected statement is stronger, not weaker. "Worse than guessing" would suggest an inefficiency that a cleverer rule might remove. "Exactly equal to guessing, for every rule" is a conservation law: the yield per candidate is invariant, so there is nothing to optimise. A negative result of the second kind closes a question; one of the first kind merely postpones it.

10.5Position against the standard attacks

Corollary 21 places the whole family at the cost of exhaustive key search, $\Theta(n)$ operations. The standard generic attack on ECDLP, Pollard's rho, costs $\Theta(\sqrt{n})\approx2^{128}$ operations on secp256k1. The classification is therefore $\approx2^{128}$ times more expensive than the baseline that the curve was designed to resist, and the gap is not an artefact of any particular class but a theorem about all of them.

Section 12Relation to real ECDSA failures

It is worth stating plainly what does break ECDSA, because the contrast is the sharpest available argument that classes A, B and E are the wrong place to look.

12.1Nonce reuse

If two signatures $(r,s_1)$ and $(r,s_2)$ on hashes $z_1\neq z_2$ share a nonce, then $r$ repeats, and $$k=\frac{z_1-z_2}{s_1-s_2}\bmod n,\qquad x=\frac{s_1k-z_1}{r}\bmod n .$$ Cost: two modular inversions. Probability of success: $1$. This is the mechanism behind the 2010 Sony PlayStation 3 code-signing compromise and the 2013 Android SecureRandom Bitcoin thefts. Detection requires nothing more than scanning the blockchain for duplicate $r$ values — a linear-time database query, not a $10^{77}$-signature search.

12.2Biased or truncated nonces

If the top $\ell$ bits of $k$ are constant or predictable, each signature yields an instance of the Hidden Number Problem, and a lattice of dimension $O(n_{\mathrm{sig}})$ reduced by LLL or BKZ recovers $x$ from roughly $O(\log n/\ell)$ signatures. Practical recoveries are routine with $\ell\ge4$ and a few dozen signatures, and Bleichenbacher-style Fourier methods extend this to $\ell=1$ given a few million signatures. This family — Howgrave-Graham and Smart; Nguyen and Shparlinski; the "Biased Nonce Sense" survey of Breitner and Heninger; the Minerva and LadderLeak side-channel results — is the reason nonce generation is the most scrutinised part of any ECDSA implementation.

Section 13Falsifiability and power analysis

The results above are conditional on Assumptions U and R. The scientifically useful question is therefore: what observation would overturn them? The answer is precise. A class whose observed frequency exceeds its predicted $c/n$ baseline by a factor $\lambda>1$ that persists as $n$ grows would demonstrate a genuine non-uniformity in the distribution of $\zeta$ — the only finding in this area that would be worth pursuing.

The one experiment worth running

Do not search for more anomaly classes; the space of arithmetic coincidences is infinite and each new one will have frequency $\Theta(1/n)$ for exactly the reasons proved in §5 and §7. Instead, test the distribution directly: take $10^{8}$–$10^{9}$ transactions on a curve with $n\approx10^{4}$–$10^{5}$, form the empirical distribution of $\zeta=zk^{-1}$ conditioned on every public statistic available, and run a uniformity test (chi-squared over $\sqrt{N}$ bins, or a discrete Fourier test à la Bleichenbacher on the residues). A null result there closes the question. A positive result would be a genuine finding, and it would announce itself as a bias in a histogram, not as an elegant identity.

Section 14Limitations

  1. Assumption R is a heuristic. The abscissa $r$ is a deterministic function of $k$; treating it as an independent uniform unit is not provable with current techniques. Its role is confined to obtaining closed forms; the predictions were checked against data generated on real curves without it, and agree within Poisson noise (Table 3).
  2. The class-B constant is empirical. $c_B\approx0.19$ is calibrated over $101\le n\le1009$ and drifts by $\approx3\%$ across that range. Only the order $\Theta(n^{-2}\log n)$ is argued from first principles, and even that rests on divisor equidistribution. Classes A and E carry no such caveat: their formulas are exact identities for every prime $n$.
  3. The analysis concerns an ideal signer only. Nothing here bears on implementations with faulty randomness, deterministic-nonce bugs, fault injection or side channels. Those are the real attack surface, and they are governed by §12, not by this paper.
  4. Union bounds are used in §9–§10. The three classes are not independent (all are conditioned on the same hidden pair), so the stated union figures are upper bounds. That is the conservative direction for the conclusion.
  5. Class C and class D are out of scope. Class C admits no closed-form recovery; class D is not a coincidence class at all but the generic case, occurring for $\approx25\%$ of all transactions by Theorem 7, and its candidate window has width $a=\Theta(n)$ on average, which makes the intersection method $\Theta(n)$ per transaction — roughly $2^{128}$ times worse than Pollard rho. The level index $N=\lfloor\zeta/a\rfloor$ is moreover a function of the secret $\zeta$, so the window cannot be located without already knowing what it is meant to reveal.

The class-B multiplier satisfies an integer quadratic (Theorem 12); modular square roots are unnecessary, and the perfect-square condition on the discriminant is far more restrictive than quadratic residuosity mod $n$. Wrap-around instances require $m\le2$ plus an exact auxiliary relation (Lemma 13) and were never observed.
  6. On secp256k1: $\Pr[\mathrm{A}]=2^{-258.00}$, $\Pr[\mathrm{E}]=2^{-256.58}$, $\Pr[\mathrm{B}]\approx2^{-506.9}$. Across every secp256k1 signature ever produced ($\lesssim10^{10}$), the expected number of instances of all three classes combined is $\approx8\times10^{-68}$.
  7. The yield per tested candidate is the constant $1/(n-2)$ for every public-data rule (Theorem 20, Corollary 21). Classification cannot improve it, and the best conceivable rule beats uniform random guessing by the factor $1+1/(n-2)=1+8.6\times10^{-78}$, earned entirely by the remark $s_{zk}\neq s$. Exhaustive key search is itself $\approx2^{128}$ times worse than Pollard rho. There is no attack here, no partial attack, and — this is the point of the theorem — no possible future one of this type.
  8. The productive research question is not "are there more classes" — there are infinitely many, all of frequency $\Theta(1/n)$ — but "is the distribution of $s_{zk}$ uniform". That question is answerable with existing data and existing tools, and the answer so far, to within $\pm2\%$, is yes.

15.1How this work should be presented

Framing

The results belong in the literature, if anywhere, as a short technical note in elementary combinatorics and its verification: exact cardinalities of a family of subsets of a finite product set, plus a conservation law (Theorem 20) that renders the family uninteresting. They do not belong in a security venue, a disclosure channel, or a preprint whose title contains the words "recovery", "vulnerability" or "attack" — not because the mathematics is weak, but because such a title would be read as a claim the mathematics explicitly refutes.

Three specific cautions follow. First, the recovery formulas should be stated only as corollaries of Proposition 3 and never as procedures, since as procedures they require an input (the value of $\zeta$) that is equivalent to the answer. Second, the phrase "$25\%$ of transactions" should never appear without Theorem 7 attached, because in isolation it reads as an exposure rate when it is the area of a triangle. Third, absolute counts such as "$10^{231}$ instances exist on secp256k1" should be reported only alongside the density $10^{-77}$; abundance without density is the single most reliable way for a null result of this shape to be misread, including by its own author.

Every number in Tables 2–7 is reproduced by the following self-contained enumeration. For $n\le1009$ it is exhaustive over all $(n-1)^{3}$ states, so the resulting probabilities are exact rationals, not estimates. 

import numpy as np, math

def enumerate_states(n):
    """Exhaustive sweep over the state space S of Lemma 4: (zeta, xi, u)."""
    v = np.arange(1, n, dtype=np.int64)
    Z, X = np.meshgrid(v, v, indexing='ij')
    Z, X = Z.ravel(), X.ravel()
    S = (Z + X) % n
    keep = S != 0
    Z, X, S = Z[keep], X[keep], S[keep]

    sig = Z + X                                    # true integer sum, eq. (2.3)
    nE  = int(np.count_nonzero((sig % 2 == 0) &
                               (np.abs(Z - X) == sig // 2 + 1)))
    nE_line = int(np.count_nonzero((Z == 3*X + 2) | (X == 3*Z + 2)))   # Thm 16
    assert nE == nE_line == 2 * ((n - 3) // 3)                          # Thm 17

    q = a_ct = b_ct = 0
    for u in range(1, n):
        ZR = (Z * u) % n
        m  = ZR > S
        z_, x_, s_, zr_ = Z[m], X[m], S[m], ZR[m]
        d  = zr_ - s_
        a  = s_ % d
        g  = (a > 0) & (a != s_) & (a != zr_)                           # Def 5
        z_, x_, s_, zr_, a = z_[g], x_[g], s_[g], zr_[g], a[g]
        q += a.size
        a_ct += int(np.count_nonzero(z_ == a))                          # class A
        t = s_ + zr_
        both = (z_ % a == 0) & (t % x_ == 0)                            # class B
        if both.any():
            b_ct += int(np.count_nonzero(z_[both] // a[both] == t[both] // x_[both]))

    tot = (n - 1) ** 3
    assert abs(a_ct/tot - (q/tot)/(n-2)) < 1e-15                        # Thm 10
    return dict(n=n, PQ=q/tot, PA=a_ct/tot, PE=nE/(n-1)**2, PB=b_ct/tot)
